## 01 — Positioning

**One-liner:**
Black Lab Visuals is an AI-driven visualization studio for construction, infrastructure, and real estate.

**What we do:**
We turn technical projects into visuals people believe in — cinematic 3D renders, retrofit before/after sequences, and interactive web experiences, produced at AI speed with studio-grade craft.

**Who it's for:**
Infrastructure and engineering firms (pursuits, public engagement), developers and real-estate teams (launches, pre-sales), and architects (design communication).

**Why us (the wedge):**
Traditional archviz studios render in days what we iterate in hours. Web agencies don't have the 3D. 3D studios don't ship the web. We do both, with an AI pipeline in the middle.

---

## 02 — Offer Architecture

### Core — Visualization (the product)
- Cinematic 3D renders and animations (Unreal Engine)
- Retrofit / redevelopment **before → construction → after** sequences (AI-accelerated with Veo/Kling)
- Street-level and public-realm visualization for community engagement

### Delivery Format A — Pursuit & Proposal Packages
Turn-key visual packages for bids and pursuits: renders + scroll-driven walkthrough + narrative copy, assembled into a password-protected interactive presentation. Built for infrastructure firms that win work with story, not spec sheets.

### Delivery Format B — Interactive Web Experiences
Scroll-driven launch sites and microsites with 3D/AI media embedded — for real-estate launches, project reveals, and stakeholder engagement. One URL that replaces the PDF deck.

> Rule for the website: the Core is the hero. Formats A and B are presented as
> "how you receive it," never as separate competing services. No mention of
> photography, videography-for-hire, or generic app development.

## 03 — Brand Story (rewrite)

**The Labrador** — loyalty, focus, quiet strength. Calm under pressure, attentive to detail, devoted to the project. The same presence we bring to every build.

**The Aperture** — six blades, perfect symmetry, engineered light control. In v1 it meant photography as craft. In v2 it means the same thing one layer up: **controlled light is controlled perception** — we engineer how a project is seen before it exists.

Tagline options (pick one, don't stack):
1. *We make the unbuilt believable.*
2. *Every project, seen before it exists.*
3. *Loyal to the vision. Precise to the frame.*

## 04 — Visual Identity (unchanged from v1.0)

| Element | Spec |
|---|---|
| Primary black | `#050505` |
| Gold accent | `#C5A572` (gold gradient permitted) |
| Headline type | Montserrat Bold — all caps, 8% tracking, weight 700–800 ("BLACK LAB") |
| Elegant type | Cormorant Garamond Light — italic preferred, generous spacing ("Visuals") |
| Body / UI type | Inter, 8px baseline grid |
| Logo | Labrador profile + integrated 6-blade aperture, golden-ratio (1.618) grid |
| Clear space | Cap height of "B" in BLACK on all sides |
| Minimums | 32px icon (digital), 20mm lockup width (print) |
| Mood | Quiet confidence. No hype, no jargon. Dark-first layouts, gold as punctuation. |

Incorrect usage rules from v1.0 carry over verbatim: never recreate the mark, approved files only, "if it looks wrong, it is wrong."

## 05 — Voice & Copy

Quiet confidence. Technical fluency without jargon. We describe outcomes (a councillor who finally understood the project; a bid that stood out) — not tools. AI is our pipeline, not our headline: mention it once, as speed and cost advantage, then stop.

**Copy examples (v2):**

- Hero: "The project exists in your head. We put it in theirs."
- Core service: "Cinematic visualization for infrastructure and real estate — rendered in Unreal, accelerated by AI, delivered in days, not weeks."
- Format A: "Your next pursuit, told as an experience. Renders, walkthrough, and narrative in one interactive, password-protected presentation."
- Format B: "A launch site that moves. Scroll-driven storytelling with your project's 3D world embedded — one link that retires the PDF."
- Proof line: "Built by the studio behind StreetVision AI and PursuitVision AI."

**Words we don't use:** disruptive, cutting-edge, synergy, revolutionize, "AI-powered" as a headline.

## 06 — Website Structure (for the builder test)

1. **Hero** — full-bleed render or walkthrough clip, tagline, single CTA ("See the work")
2. **Work** — 3–4 case tiles (PursuitVision demo, StreetVision, Unreal renders); each opens a scroll case study
3. **What we do** — Core first, then Formats A and B as two cards under it
4. **Process** — brief → riskiest-assumption validation → iterate → deliver (mirrors your real workflow; clients read it as rigor)
5. **About** — the labrador story, one paragraph, one portrait-of-the-mark image
6. **Contact** — hello@blacklabvisuals.co, no forms with more than 3 fields

Footer carries over v1.0: contact block, legal block, `#050505 / #C5A572` signature line.
